# Releases

## v1.0.0 (Initial Release & Fixes)

### Key Updates:
- **Build Portability**: Replaced hardcoded local file paths with relative `lib/` directory references.
- **Entry Point Fixed**: Corrected default execution target to launch `Main` application window instead of empty class.
- **Dependency Standardization**: Cleaned standard JDBC imports for MySQL compatibility.
- **Launch Scripts**: Added standalone `run.bat` and `run.ps1` to compile and run without needing NetBeans IDE.
- **Documentation**: Added setup instructions and database configuration in `README.md`.
